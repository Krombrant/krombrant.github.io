Política de privacidad

Cerebro Personal — aplicación personal de Google

Esta aplicación es de uso personal y tiene un único usuario: su autor. No tiene servidor propio, no tiene otros usuarios y no vende ni cede datos.

Qué datos usa

Con la autorización explícita del usuario, la aplicación accede a su propia cuenta de Google: correo de Gmail, Google Calendar, Google Drive, Documentos y Hojas de cálculo. Lo hace solo cuando el usuario lo pide.

Cómo se usan

La aplicación corre en la computadora personal del usuario. Cuando él lo solicita, el contenido que pide se entrega a un asistente de inteligencia artificial (Claude, de Anthropic) para responder esa consulta. Ese es el único tercero que recibe datos, y solo lo que el usuario pide en cada momento.

Dónde se guardan

La aplicación no tiene base de datos ni almacenamiento propio en la nube. Los registros de las conversaciones del asistente quedan en el disco de la computadora del usuario.

Con quién se comparten

Con nadie más. Los datos no se venden, no se publican, no se usan para publicidad y no se usan para entrenar modelos de terceros por parte del autor. La aplicación no incorpora analítica ni rastreo.

Uso limitado

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos del usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Credenciales

Las credenciales de la aplicación y los tokens de acceso se almacenan en el Llavero de macOS del usuario. No se registran en archivos de texto ni de configuración.

Retención y baja

El usuario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions y borrar los registros locales de su equipo.

Cambios

Si esta política cambia, la versión vigente será siempre la publicada en esta dirección.
